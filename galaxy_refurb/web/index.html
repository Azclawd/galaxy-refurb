Refurbishing

    How it works

    Plug in a phone. When it stands up and glows, press Start. Follow any card that pops up in the bottom right. Everything else is automatic, and each step ticks off as it passes.

    Samsung USB driver

    Windows needs Samsung's USB driver once. Get it from developer.samsung.com/android-usb-driver, run it, then replug the phone.

    Firmware

    Firmware downloads automatically from Samsung (5-12 GB the first time for each model, then it's reused). To add it by hand, put the official zip in Documents\GalaxyRefurb\firmware\<MODEL>.

    Locked phones

    Phones locked to a store's Knox account or a previous Google/Samsung account can't be unlocked by software. They're marked Return to seller with the IMEI so the seller can release them.

    Something failed?

    The red card explains what happened and what to do, and shows the log lines. Full logs are under Logs (top right). Send one if you need help.
